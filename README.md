# 拾词 · English Companion

在阅读中积累英语表达，再通过主动回忆与间隔复习把它们留下来。支持中文与英文界面。

当前版本：**1.2.0**。这是一个无需构建、无需运行后端、无需安装运行依赖的 Chrome Manifest V3 扩展；需要用户自行配置模型服务或本地模型。

## 功能一览

- **划选翻译**：单词、词组、句子的中英互译，以及用法与例句。
- **自选模型**：DeepSeek、智谱、OpenAI、Ollama 或其他 OpenAI 兼容接口。
- **本地生词本**：收藏、搜索、删除与 JSON 导出。
- **回到语境**：生词卡和复习卡提供低调的「阅读原文」入口。
- **间隔复习**：八个回忆检查点、未来七天安排、进度条与掌握状态。
- **双语界面**：中文 / English 随时切换并保存偏好。

## 仓库与个人数据

本仓库只发布源代码、文档和使用虚构数据的测试。**不要将自己的 API Key、生词导出、浏览器配置目录或个人阅读记录提交到 Git。**

实际 API Key、生词、来源 URL 与学习进度由插件存入浏览器的 `chrome.storage.local`，并不写入项目源文件，也不会随 Git 提交自动上传。源码中的 `apiKey` 等字段名、空默认值及测试中的 `fake-key` / `test-secret` 等仅是程序定义或虚构测试值。

`.gitignore` 已排除 `.env`、私钥、常见生词导出文件、`data/`、`exports/`、`backups/`、浏览器配置与截图等目录。建议将自己的备份统一放到被忽略的 `exports/` 或 `backups/` 中；忽略规则不会自动保护已经被 Git 跟踪的文件。提交前可用 `git status --short` 和 `git diff --cached` 检查。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目目录（包含 manifest.json 的文件夹）。
4. 将「拾词」固定到工具栏，点击图标 →「模型与 API 设置」。
5. 选择服务商，填写 API Key、完整接口地址和模型名称，保存后测试连接。
6. 刷新已打开的普通网页，划选文字即可翻译。

## 使用

- 网页划选单词、词组或句子会自动中英互译，可收藏到生词本。支持 Shift + 方向键选中文字后松开 Shift。
- Esc 或点击弹窗外关闭翻译卡；输入框、编辑区不触发划词。
- 工具栏弹窗支持手动输入翻译、调整方向和暂停划词。
- 学习空间右上角和工具栏弹窗提供「中文 / English」界面切换，立即生效并保存。界面语言不影响翻译方向、已收藏译文或模型配置；新打开的网页翻译卡也使用所选语言。
- 生词本支持原文/译文搜索、查看例句、来源跳转和删除。
- 每日复习先显示原文，揭晓答案后选择「还没记住」或「记住了」。记住后的间隔为 1、3、7、14、30、60、120 天；没记住则 10 分钟后复习。新收藏立即进入复习。
- 每条生词显示复习进度条（8 个回忆检查点）、掌握程度图标和下次复习时间；展开时间线可查看阶段与预计日期。每日复习页显示未来七天已排定的复习数量，到期记录按时间排序；此前逾期的记录归入今天。
- 网页收藏保存完整来源 URL（包含查询参数和锚点），生词卡底部和复习卡底部用低调的「阅读原文 ↗」链接返回文章，在新标签页打开，不展示长 URL。手动输入翻译的收藏没有网页来源。旧记录保留已有链接，历史缺失的参数无法自动恢复。
- 导出生成 JSON，包含学习内容和复习记录，不含 API Key。当前版本不含导入功能。

## 模型配置

预置 DeepSeek、智谱、OpenAI、Ollama；可改为任意提供 OpenAI 兼容 `POST /chat/completions` 接口的文本模型服务，包括托管开源模型。

填写**完整地址**，不是只填域名或 `/v1`。模型名称必须使用账户实际可用的模型 ID；预置名称仅为起点，供应商可能调整可用模型。

- DeepSeek：`https://api.deepseek.com/chat/completions`
- 智谱：`https://open.bigmodel.cn/api/paas/v4/chat/completions`
- OpenAI：`https://api.openai.com/v1/chat/completions`
- Ollama：`http://localhost:11434/v1/chat/completions`，模型名填写本地已安装的模型；可留空 Key。需要本地服务允许运行中的扩展来源访问。

原生 Anthropic、Gemini 等非 Chat Completions 协议需要兼容网关；仅有 API Key 不能自动兼容所有协议。接口超时为 25 秒，单次输入最多 6000 字符。连接测试会向已保存的服务发送一条短翻译请求，可能产生少量费用。

## 间隔复习规则

遗忘曲线描述记忆随时间的变化；间隔重复配合主动回忆用于巩固记忆。研究并没有给出适合所有人、所有材料的唯一艾宾浩斯日期表。本插件使用可解释的实用递增间隔，而不是声称估计了个人遗忘概率：

1. 收藏后立即进行首次主动回忆，揭晓答案后自评。
2. 连续记住时，依次等待 **1、3、7、14、30、60、120 天**后再回忆。间隔从上一次记住的实际时间起算，并非收藏后的累计第几天。8 个检查点包括首次回忆以及这 7 次到期回忆。
3. 完成全部阶段后，继续每隔 120 天复习。不会因为进度满格就停止长期维护。
4. 忘记时保留总复习次数与历史记录，阶段回到重新巩固，10 分钟后再试。再次记住后从 1 天间隔继续。
5. 到期前不能重复评分来提高阶段；逾期后只需完成当前这一次，不必补做多轮。后续间隔从这次实际评分时间起算。

掌握状态为「尚未学习／初步记住／正在巩固／比较熟悉／较牢固」，根据连续成功的阶段粗略描述；不是记忆概率。进度条表示已完成检查点数量。忘记后显示「重新巩固」；到期与逾期另外提示。未来日期假设后续都能记住，失败或延期会调整。保留最近 50 次评分，界面展示最近 5 次。

旧数据沿用原有到期时间、复习次数和 step 所对应的进度，不伪造历史日期；此后每次评分会保存新格式的进度及记录。学习空间打开时自动更新到期显示，无系统通知。

研究参考：[Cepeda 等，2008，Spacing Effects in Learning](https://laplab.ucsd.edu/articles/Cepeda%20et%20al%202008_psychsci.pdf)。研究表明合适的复习间隔与期望保持时间有关，不支持将本插件这组间隔称为唯一标准。

## 数据与隐私

密钥与生词保存在 `chrome.storage.local`，不上传到本产品服务器、不启用云同步。密钥存储限定插件可信上下文，网页脚本无法直接读取。密钥并非加密保险库，具有本机浏览器访问权限的人仍可能读取；共享设备请清空 Key 并保存。翻译时只向配置的 API 发送选中文字，不发送整页、网页来源或生词本。网页来源完整 URL 会随生词保存在本地并包含在生词导出中；分享导出文件前请留意链接中可能包含的个人参数。

插件需要普通网页内容脚本来读取划选，以及 HTTPS 接口访问权限来支持自定义服务。Chrome 内置页面、Chrome 网上应用店、内置 PDF 阅读器等受限制页面不支持网页划词，可使用工具栏手动翻译。更新扩展后需刷新网页。卸载扩展会清除本地数据，建议先导出。未上架 Chrome 网上应用店。

## 开发与验证

运行 `npm test`（Node 20+，无须安装依赖）。测试覆盖 URL 校验、模型响应解析、复习调度、密钥访问限制、并发收藏、重复收藏和模拟 API 请求。

可选浏览器检查：先运行 `npm install --no-save playwright`，再运行 `node tests/browser-smoke.mjs`；优先使用本机 Chrome/Edge，也可通过 `CHROME_PATH` 指定可执行文件；没有本机浏览器时，可运行 `npx playwright install chromium` 安装测试浏览器。该检查使用模拟 Chrome API 和模拟翻译结果，验证页面交互与内容脚本；不等同于加载真实扩展或连接真实模型。Playwright 仅用于开发测试，使用插件不需要安装。

手动验收：配置接口并测试 → 打开普通文章网页并刷新 → 划选英文/中文/词组/句子 → 收藏 → 搜索 → 复习揭晓与评分 → 导出 → 重启浏览器检查数据。再检查错误 Key、超时和停用划词。

## 常见问题

- **修改代码后没有变化**：到 `chrome://extensions` 重新加载扩展，再刷新设置页和已打开的文章网页。
- **配置已保存但连接失败**：检查完整的 `/chat/completions` 地址、模型 ID、Key、余额和网络。测试按钮使用已经保存的配置。
- **有的页面不能划词**：Chrome 内置页面等受浏览器限制，可改用工具栏手动输入。
- **暂时没有待复习内容**：未到期的记录只显示在日程中，不允许提前重复评分；到期后自动进入队列。
- **导出文件可以公开分享吗**：导出不含 API Key，但包含词语、译文、完整来源 URL 和学习记录，属于个人数据。

参考：[Chrome storage](https://developer.chrome.com/docs/extensions/reference/api/storage)、[DeepSeek API](https://api-docs.deepseek.com/)、[智谱文档](https://docs.bigmodel.cn/)。
